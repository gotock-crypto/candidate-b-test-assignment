# Decisions

1. Статус на дату среза определяется по датам приёмки и отмены, а не только по текущему статусу выгрузки.
2. Фактическая оплата определяется по `paid_at`; `queued` исключается, оплаты после 10.11.2026 не учитываются.
3. Возврат уменьшает выплату начиная с `refunded_at`; отсутствие даты возврата считается ошибкой.
4. Непривязанные авансы распределяются пропорционально цене работ, не отменённых к дате отчёта. Остатки копеек распределяются методом наибольшего остатка с сортировкой по `work_id`. Это допущение, которое должен подтвердить бухгалтер; альтернативы — FIFO, равные доли или сохранение нераспределённого остатка.
5. Отменённые работы показываются отдельно и не получают долю общего аванса. Прямые выплаты по ним сохраняются видимыми.
6. Переплаты не скрываются: отрицательный остаток показывает сумму превышения. Перенос между работами/договорами автоматически не выполняется.
7. Деньги считаются в целых копейках, без `float`; результат формируется в CSV.

Если учётная политика отличается от указанных допущений, пересчёта потребуют распределение авансов, остатки по работам и трактовка платежей по отменённым работам.

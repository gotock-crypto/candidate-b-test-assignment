# Тестовое задание Candidate-B

CLI-программа на Python для формирования отчёта по договорам и работам на дату среза. Все денежные операции выполняются в целых копейках.

## Запуск

```bash
python report.py --data-dir data --date 2026-11-10 --output report-2026-11-10.csv
```

Python 3.10+, сторонние зависимости не нужны.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Состав

- `report.py` — CLI и расчётная логика
- `data/` — исходные CSV и формат данных
- `tests/test_report.py` — 41 автоматический тест
- `report-2026-11-10.csv` — сформированный отчёт
- `DECISIONS.md` — решения и ограничения
- `ACCOUNTANT_NOTE.md` — вопросы для проверки бухгалтером
- `opencode-session-final.json` — оригинальный экспорт истории OpenCode (GPT-6 Luna)

## Допущения

Непривязанные авансы распределяются пропорционально стоимости работ, не отменённых к отчётной дате, методом наибольшего остатка. Это допущение не является подтверждённой учётной политикой. Порядок оплаты отменённых работ и переноса переплат требует подтверждения бухгалтером.

В задании разрешено использовать Claude Code и другие ИИ-инструменты; история реализации приложена в оригинальном формате OpenCode.
